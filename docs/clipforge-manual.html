01

全局地图：18 个页面与四步主链

ClipForge 不是「一个页面做完所有事」，而是把一条片子的生产拆成四步，每步一个页面；其余页面是入口、资产库、旁支工具和全局设置。

四步主链

STEP 01
脚本方案
生成 / 选方案 / 判官团审稿 / 编辑分镜文案
STEP 02
素材生成
逐镜生关键帧图 → 图生视频 → 首尾帧衔接
STEP 03
视频时间线
配音 / 字幕 / BGM / 贴片 / 开始合成
STEP 04
导出
下载成片 / 发布文案 / 质检 / 多平台导出

顶部的四个步骤胶囊是普通链接，可自由跳转，不是必须解锁的关卡。当前步由 URL 后缀判定。一个例外：video 页仍在用自己的旧版内联 stepper，不可点击（project-stepper.tsx:25 注释里明确说明待统一）。

18 个页面按角色分组

项目状态机

数据库里 projects.status 的枚举是 draft → scripting → assets → video → composing → done，但实际改写点集中在几个地方：

时机写入值触发者
建项目draft数据库默认值
生成脚本 / 主题成片scripting/api/llm/script、/api/topic/script
开始合成composing/api/project/[id]/compose
合成成功 / 失败done / 回退 video合成路由；失败时回退以便重跑
容易误判

assets 状态只出现在枚举、文案和「继续未完成项目」的映射里，代码中未见实际写入点。实践中状态常从 scripting 直接跳到 composing，所以不要靠状态值判断「素材是否已经生成完」——要看素材页的 {done}/{total} 个素材已就绪。

侧边栏与界面模式

侧栏分「创作」与「资产库」两组。其中 新建项目、媒体实验室、批量出片 标了 proOnly，只在导演模式显示；默认是小白模式。切换在设置里（uiMode），侧栏折叠状态记在 clipforge_nav_collapsed。铃铛打开任务中心，汇总进行中、待处理和最近 24 小时成片。

02

工作台 /start 与生产档位

这里是绝大多数片子的起点。三种输入方式最终都会创建一个项目、生成一版脚本，然后把你送到脚本页。

三种输入

上传商品图

建项目 → 上传图（最多 5 张，JPG/PNG）→ 写回 productImages → 生成脚本 → 脚本页。商品图会复用为保真参考。

一句话主题

输入如「在家如何泡一杯手冲咖啡」，走 /api/topic/script，无需商品图，属于 topic 模式。

商品链接

粘贴店铺链接，走 /api/ingest/product 抓取标题、价格、图片，再生成脚本。

两条出片路线

路线做什么适合
免费快剪服务端链 判官团 → 自动配画面 → 合成，状态写进 pipelineRuns，关掉页面也不丢，可从断点续跑先看结构、不花钱
AI 出片逐镜 AI 生图 + 图生视频，走配置的生图/生视频平台；只有一次显式确认后才计费正式成片

智能生产方案（三档）

只在 AI 出片模式下出现。它会一次性写入一整套全局参数，但不会替换你已经选好的模型。这是理解后面所有「单镜时长 / 运动强度」的来源。

档位分辨率单镜时长运动强度运镜接缝画面风格
极速试片 rapid720p4s0.35轻独立镜头默认
智能均衡 balanced720p5s0.55中关键帧衔接日间清透
品牌大片 cinematic1080p8s0.72强尾帧续拍棚拍质感

默认 balanced。「精调参数」链接会跳到 /settings?tab=video；三个档位定义在 src/lib/production-profiles.ts:22-63。

点击路径（开发者视角可隐藏）

上传图：POST /api/project → POST /api/upload → PATCH /api/project/[id] → POST /api/llm/script → /project/[id]/script?auto=1。主题：POST /api/topic/script。链接：POST /api/ingest/product → POST /api/llm/script。爆款复刻还会串 /api/replicate/analyze 与 /api/ai/video。

04

最复杂、也最需要理解的一页。它把「每个分镜的一张关键帧图」变成「一段视频」，再把视频交给时间线。

逐镜生图
每个 shot 生成一张关键帧
2
转动态
以关键帧为首帧做图生视频
3
接缝处理
钉帧 / 续拍 / 关，衔接相邻镜头
4
诊断与恢复
废片重投、云端任务恢复查询

此外有运镜预设（可为单镜推荐、最多叠两层）与全局画面风格预设。模型能力预检会显示六个徽标：图生视频、首尾帧、多图参考、参考视频、原生音频、声音参考；能力不匹配时会给出「时长自动适配 / 清晰度自动适配 / 画幅自动适配 / 镜头衔接降级」提示。

与本地 ComfyUI 最相关的一条

每镜视频时长不是固定 5 秒。代码是 clamp(4, 15, round(asset.duration))，其中 asset.duration 来自脚本该镜的配音槽位；只有缺省时才用全局 videoParams.duration（默认 5）。本地 ComfyUI 会把它换算成 4k+1 帧，5 秒 = 121 帧。

05

视频时间线与合成

把素材页产出的每段视频按脚本顺序排好，叠加配音、字幕、音乐与贴片，然后交给 FFmpeg 渲染成片。

区块可选项 / 文案说明
时间线N 个片段 · 总时长 Ns转场标签：AI 智能过渡 / AI 参考过渡 / 直接拼接 / 渐变过渡
配音启用自动配音 · 试听这个音色免费 Edge 音色（晓晓 / 晓伊 / 云希 / 云扬 / 云健）无需 Key；也可复用已配置的付费 TTS
字幕底部 / 居中 / 顶部；标准底板 / 重击大字 / 极简 / 卡拉OK逐字字幕位置与四种样式
BGM无 / 轻快节奏 / 舒缓放松 / 动感活力 / 情感温暖；上传 BGM旁白闪避会在配音处自动压低音乐；上传 mp3
带货转化片尾购买 CTA · 商品卡贴片商品卡需要商品图
画面设置竖屏 / 横屏 / 方形；分辨率；快速 / 标准 / 高清渲染质量档
风格配方导入配方 · 导出当前设置纯前端 JSON，便于复用一套合成设置
合成开始合成 · 重新合成 · 合成中… N% · 下载视频POST compose + GET 轮询，间隔 3s，前端总超时 5 分钟
变体矩阵变体矩阵（A/B 批量出片）· 批量合成 N 条维度：钩子文案 / 字幕样式 / 配乐情绪；上限 6 条，顺序合成
超时不用慌

合成超时只代表前端停止轮询，服务端渲染仍在跑。去导出页看历史成片即可，不要重复点「开始合成」。

服务端 pipeline 的 compose 轮询更长（2.5s × 288 ≈ 12 分钟），所以「免费快剪」比手动合成更能耐受长片。

06

导出页与发布门禁

成片在这里下载，但这一页真正的价值是「发布前的一整套检查与衍生资产」。

主成片与文案

下载视频、复制视频链接、历史成片列表；AI 生成标题/话题（无 LLM 时用免 Key 模板）、种草文案、带追踪的商品链接、评论区运营包、AI 内容声明。

更多产出

封面图、小红书图文卡片、扫码购买二维码、片尾扫码成片、多语言译制版。

发布门禁 / 成片质检

一键体检汇总脚本、成片、AI 镜头验收、素材授权与平台风险；质检给出通过 / 警告 / 不通过。

审片与授权

成片速览图（720p + 时间码）、素材授权清单（Markdown 下载）、原生感处理（轻微 / 明显 / 边走边拍）。

多平台导出

支持抖音、快手、小红书、视频号、TikTok Shop、Instagram Reels、YouTube Shorts。构图方式三选：模糊背景·完整保留 / 黑边留白·完整保留 / 满屏裁切·调整位置。

发布门禁的判定规则

最差状态胜出
任一 fail → 整体 fail；否则任一 warn → warn；都没有才 pass
六个检查项
readiness / QC / 镜头质量 / 素材授权 / AI 政策 / 实拍占比
硬性拦截
人工标记「不采用」的当前镜头会直接拦下发布
合规默认
AIGC 角标默认开启、烧在片头 ≥2 秒；可关闭但门禁会报风险
抖音节奏要求
商品必须在前 3 秒出现；时长 15–60 秒（45 秒以内最佳）；实拍占比 ≥50% 才有混合内容倾斜
未完成

「进阶工具 → A/B 变体」在导出页带「开发中」徽标，尚无实现；批量 A/B 请去视频时间线的变体矩阵。

设置是全局的、按浏览器保存的。它不属于某个项目，换项目不重置；但换浏览器或换端口就会读不到（见第 11 章）。

为什么生图 / 视频模型页会显示「请先启用 AI 平台」

这两个下拉本身不注册平台。数据流是：平台 Key 里 enabled && apiKey 的平台 → POST /api/ai/models 逐个调 listModels() → 合并结果填进下拉。所以添加平台要去「平台 Key」，不是在这两页；这里只负责选默认模型。所有改动即存，无需点保存。

自定义模型接入点

填「归属平台 + 类型 + model id + 显示名」，往浏览器 store 里追加一条记录，让上方默认模型下拉多一个选项。它不下载权重、不校验模型存在、不创建任何工作流。用途是平台上了新模型、而项目内置清单还没更新时，手动挂一个 id 字符串。

最常见的误操作

在「添加模型」里填一个随意字符串（例如 2）并挂到 ComfyUI，会得到一个「看起来是独立模型、实际跑同一张图」的选项；若类型选成「生图」，选中后还会报 NO_IMAGE_MODEL。本次改造后，ComfyUI 只认第 09 章列出的 id 与写法。

生产档位（极速/均衡/大片）不在设置页选，在 /start 的 AI 出片模式里；设置页的「系统诊断」折叠区会调 GET /api/health，可复制不含密钥的诊断信息用于反馈。

关于「运动强度」的诚实说明

shift 改的是噪声调度，不是物理意义上的运镜幅度：调高会让帧间变化更活跃、细节更锐，但不会让镜头「推得更快」。真正决定运镜方向的是素材页的「运镜 轻/中/强」与提示词。

一条视频是怎么跑出来的

1 · 提交
POST /api/ai/video → submitVideoTask，本地首帧被转成 data URI 后解码、按内容哈希上传 ComfyUI 的 /upload/image
2 · 入队
POST /prompt 提交一张 12 节点的 API 图，返回 prompt_id 即 taskId，立刻写入 ai_tasks
3 · 等待
交叉查询 /history/{id} 与 /queue；轮询窗口按 60 分钟反算次数（默认 5s × 720）
4 · 落地
完成后取 /view，写入 data/uploads/provider-videos/，返回 /api/files/...；上层直接接受，不再二次下载

节点图由 provider 自己构造（不读用户的 workflow.json）：UNETLoader → ModelSamplingSD3 → KSampler，Wan22ImageToVideoLatent 提供 latent，VAEDecode → CreateVideo(24fps) → SaveVideo。首帧连上 start_image 就是图生视频，不连就是纯文生视频。

已知限制

  • 不生图：本机 ComfyUI 的 checkpoint 候选为空，只有 Wan 视频权重。「生图模型」下拉不会出现 ComfyUI；要用本地生图，得先放一个 SDXL/FLUX 检查点并扩写 provider。

常见症状 → 原因 → 处理

下拉显示「请先启用 AI 平台」／模型清单空白
平台 Key 里没有 enabled && apiKey 的平台，或换了 origin（端口/域名）导致 localStorage 读不到。去「平台 Key」重新启用，确认地址栏与之前一致。ComfyUI 的 Key 填任意非空值即可。
「缺少 API Key，请先在设置中配置对应平台」
/api/ai/video 与 /api/ai/video/task 都会硬校验 apiKey 非空，这是给云端平台准备的统一规则。本地 ComfyUI 也要填一个占位值（如 local）。
「连不上 ComfyUI（http://127.0.0.1:8188）」
ComfyUI 没启动、端口不对，或地址写成 localhost 而服务只监听 IPv4。先用浏览器打开 http://127.0.0.1:8188/system_stats 验证；设置页卡片的「测试连接」走同一个探针。
生成任务超时 / 页面刷新后找不到结果
付费/本地任务在提交瞬间已写入 ai_tasks。去素材页点「恢复查询」，或从铃铛的任务中心进入；不要重复提交，否则会再排一次队（本地模型就是再花 7 分钟）。
字幕 / 价格贴 / 封面报「drawtext 滤镜不存在」
Homebrew 的 ffmpeg 9.x 缺 freetype / libass / harfbuzz，没有 drawtext。启动 dev 时必须注入项目自带的 ffmpeg-static（6.0，滤镜齐全）：FFMPEG_PATH 与 FFPROBE_PATH。Docker 镜像也会在构建时校验 drawtext 是否存在。
「AI 生成标题/话题」失败或返回空
多见于思考型本地模型（如 Ollama qwen3 系列）：思考链吃满输出上限，正文为空。换成 instruct 类小模型，或清空脚本模型 Key 走免 Key 模板版。
ComfyUI 选了模型但速度/画质没变化
确认 model id 是三档之一或 @N 语法；其它字符串会静默回退标准档。服务端日志 [comfyui] model=… preset=… steps=… 会给出实际档位。
一条片跑了很久还没结束
分镜数 × 单镜耗时。标准档 5 秒/镜实测 434 秒，6 镜约 43 分钟；ComfyUI 队列自身串行。用快速档先看效果，或把高级面板里的时长降到 4 秒（97 帧）。
